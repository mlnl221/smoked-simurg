### 1. `type` — Type

**HTML field:** `name="type"`

# 2. `publicationid` — Find existing Publication

**HTML field:** `name="publicationid"`

**UI label:** `Find existing Publication:`

**Rule:**

Search Simurg for an existing Publication before creating a new one.

Search using:

* canonical magazine title;
* alternate title/spelling;
* language;
* country;
* publisher;
* ISSN;
* known publication variants.

If an existing Publication represents the same magazine, **select it**.

If the correct Publication does not exist, leave it unselected and create a new Publication.

### Important

A Publication is the **stable identity of the magazine itself**.

For example:

```text
Publication:
Penthouse Russia
```

Individual issues belong underneath that Publication:

```text
Penthouse Russia
├── November 2004
├── December 2004
├── January 2005
└── ...
```

Do not create a separate Publication for every issue.

# 17. `bitrate` — Source

**HTML field:** `name="bitrate"`

**UI label:** `Source:`

The field name is misleading: **this is not a bitrate field for magazines.**

The actual options are:

```text
Retail
Scan
OCR
Convert
Other
```

The AI should treat this as:

```text
Source = provenance/production source
```

### Retail

Use only for a **born-digital file obtained from an authorized publisher or retail distribution channel**.

A clean-looking PDF is not sufficient evidence.

### Scan

Use when the PDF/files consist of page images produced from a physical magazine.

### OCR

Use when a scanned publication has been processed/reconstructed using optical character recognition.

Check the searchable text throughout the document.

### Convert

Use when the uploaded file was derived from another digital format.

Where known, explain the input format and conversion in the Release description.

### Other

Use when the source is known but doesn't fit the other categories.

**Never use `Other` merely because the source is unknown.**

If provenance cannot be established, flag it for review.

```text

```

Don't claim something is a scan/OCR/conversion unless the evidence supports it.
